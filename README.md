# Hotel Lobby AI Generator

Hotel Lobby AI Generator turns two photos into a short, playful performance video set in a Hotel Lobby studio.

The flow is simple:

1. Upload two subjects, one for the left side and one for the right side.
2. Send them through the fixed Hotel Lobby workflow, built around an orange recording-studio scene with a suspended microphone.
3. Follow the task status and receive an MP4 when generation is complete.

Visit the product at [hotellobbyaigenerator.com](https://hotellobbyaigenerator.com/).

This repository contains product information and updates.

Early access: video generation is being prepared for public availability.
